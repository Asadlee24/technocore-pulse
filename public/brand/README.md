# FLOP official logo assets

Source: https://flop.finance/brand/
Design system: https://flop.finance/design.md

Original downloads, unchanged:
- https://flop.finance/assets/flop-lockup-on-dark.png
- https://flop.finance/assets/flop-lockup-on-light.png

The reversed lockup is displayed on Base #0A1128 with its original proportions. The header keeps the artwork above 200 CSS pixels and preserves at least 4X clear space. The community pavilion uses the unmodified file on a Base sign, with tone mapping disabled for the logo and substrate. This project is an independent community visualization, not an official FLOP Labs product.
